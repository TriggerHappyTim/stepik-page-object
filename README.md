# Page Object Model — автотесты интернет-магазина (Stepik, Selenium + Python)

Финальный проект курса «Автоматизация тестирования с помощью Selenium и Python»
(модуль 4 «Применение паттерна Page Object Model»).

Тесты написаны в стиле Page Object: в тестах нет `assert`, все действия и проверки
вынесены в методы классов страниц, все селекторы лежат в `pages/locators.py`.

## Структура проекта

```
.
├── conftest.py            # опции --language / --browser_name и фикстура browser
├── pytest.ini             # регистрация меток
├── requirements.txt       # зависимости
├── pages/
│   ├── __init__.py
│   ├── base_page.py       # BasePage: открытие страницы, поиск, ожидания, капча
│   ├── basket_page.py     # страница корзины
│   ├── locators.py        # все локаторы
│   ├── login_page.py      # страница логина и регистрации
│   ├── main_page.py       # главная страница
│   └── product_page.py    # страница товара
├── test_main_page.py      # тесты главной страницы
└── test_product_page.py   # тесты страницы товара
```

## Установка

```bash
python -m venv env
source env/bin/activate      # Windows: env\Scripts\activate
pip install -r requirements.txt
```

## Запуск тестов

Все тесты:

```bash
pytest
```

Только тесты, отмеченные для рецензирования:

```bash
pytest -v --tb=line --language=en -m need_review
```

Другой язык интерфейса и браузер:

```bash
pytest --language=es --browser_name=firefox test_product_page.py
```

## Что проверяют тесты

`test_main_page.py`:

- гость может перейти на страницу логина с главной страницы;
- на главной странице есть ссылка на логин;
- в корзине, открытой с главной страницы, нет товаров и есть сообщение о пустой корзине.

`test_product_page.py`:

- гость может добавить товар в корзину (с прохождением капчи `?promo=...`);
- название товара и его цена совпадают с сообщениями об успешном добавлении;
- в корзине, открытой со страницы товара, нет товаров;
- гость может перейти на страницу логина со страницы товара;
- зарегистрированный пользователь может добавить товар в корзину
  (регистрация выполняется в фикстуре `setup`);
- отрицательные проверки отсутствия сообщения об успехе
  (`is_not_element_present` и `is_disappeared`), тесты с известным багом помечены `xfail`.
